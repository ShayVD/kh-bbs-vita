# Firmware function signatures for tools/oracle/trace_diff.py.
#
# Both emulators log all 8 argument registers and $v1 for every call, whatever
# the function really takes, so the unused slots hold leftover data. This table
# says which values mean something. One line per function:
#
#   NAME  NARGS  RET        NAME's NID is SHA-1 based (import_report.nid_of)
#   0xNID NARGS  RET        for NIDs that are not SHA-1 of a name
#
# NARGS: the number of argument registers used (a0-a3, then t0-t3), or a list
# of register indices like 0,2,3,4 when one is skipped (a 64-bit argument
# starts on an even register).
# RET: i  32-bit result in $v0
#      u  32-bit kernel-object UID or fd in $v0, which each side allocates
#         its own way (trace_diff --map-uids learns a mapping from these).
#         Never addresses: heap placement is what the oracle has to compare.
#      l  64-bit result in $v0:$v1
#      v  nothing compared (void, or a float in $f0)
#
# Signatures follow the public PSP homebrew SDK (pspsdk) prototypes. A function
# missing here is compared on every non-null argument and $v0; add it only
# when its prototype is certain.
